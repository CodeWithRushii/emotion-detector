# Emotion Detection

Project name: **Emotion Detection** (final_project)

This is the final project for the IBM Coursera course **Developing AI Applications with Python and Flask**.

The application analyzes customer feedback text and detects emotions using the Watson NLP Emotion Predict function: anger, disgust, fear, joy, and sadness. It also returns the dominant emotion.

## Project details
- Package: `EmotionDetection`
- Main function: `emotion_detector`
- Web app: Flask on `localhost:5000`
- Route: `/emotionDetector`
